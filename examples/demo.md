# textdesk — демо-страница

Это статичный снимок текста, вшитый в index.html. Живой редактор запускается через serve.py: он читает файлы с диска, а Ctrl+S пишет правки обратно; снаружи корня — только чтение.

## что умеет
- подсветка кода на highlight.js, режим книги со страницами и мгновенным переворотом
- навигатор по папкам и поле пути: абсолютный путь внутри корня — с сохранением, снаружи — только чтение
- колонка номеров строк, память последнего файла, темы светлая и тёмная, размер шрифта A±

```python
import os

def run(root: str) -> None:
    """запуск локального сервера textdesk"""
    print(f"textdesk: {os.path.abspath(root)}")
```

правь текст, листай книгу, копируй целиком — всё локально.
