# textdesk

локальный веб-просмотрщик/редактор текстовых файлов: открывается в браузере,
Ctrl+S пишет правки прямо на диск, снаружи корня сервера — только чтение.

## файлы
- gen.py — сборка index.html из текстового файла: `python3 gen.py [вход.txt] [выход.html]`
- serve.py — сервер на 127.0.0.1: статика + запись: `python3 serve.py [порт] [корень]`
- test_viewer.py — дымовой тест (playwright + системный chrome): `python3 test_viewer.py`
- hljs.min.js — вендоренный highlight.js (BSD-3), не генерится

## правила
- index.html — сгенерённый артефакт: руками не править, только через gen.py
- после правки gen.py: `python3 gen.py && python3 test_viewer.py`
- интерфейс в px, масштабируется только текст (книжный режим масштабирует колонку чтения)
- книжный режим читается только с переносом: applyWrap внутри книги принудительно включает soft wrap, кнопка переноса скрыта, выход возвращает прежнюю настройку; продолжения перенесённых строк сдвинуты на 2ch (висячий отступ), первая строка логической строки — у гаттера
- страница книги — фиксированные N строк экрана: шаг страницы = N × pitch, где pitch = round(размер шрифта × --book-lh-ratio), и все строки холста кратны pitch (line-height книги = --book-lhp, min-height строки = 1lh). поэтому граница страницы всегда попадает на границу строки экрана и половинчатых строк нет; страница может начаться с продолжения логической строки — это нормально для читалки, номер у неё не показывается
- #backw — окно обрезки холста: #back внутри него ездит трансформом. в книге окно совпадает с полем textarea (left/right/top/bottom = --bpx/--bpy), поэтому соседняя строка не подглядывает в поля карточки, а ширина окна + 2ch компенсирует висячий отступ, чтобы перенос совпадал с textarea и высоты не разъезжались
- hljs: подсветка по вьюпортному окну, цвета токенов — переменные --tok-* в обеих темах
- запись — только внутрь корня, текстовые расширения из ALLOWED_EXT/ALLOWED_NAMES, Origin сверяется
