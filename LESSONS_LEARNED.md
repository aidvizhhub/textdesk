# Грабли (только постфактум, из реальных факапов)

- file:// (и особенно файрфокс) писать в файлы не умеет: «сохранить» без сервера = копия в Загрузки. для записи — serve.py.
- serve.py не стартует, если старый процесс держит порт 8792: сначала `pkill -f serve.py`, потом запуск. тест сам берёт свободный порт.
- правки index.html руками затираются следующим `python3 gen.py` — источник только gen.py.
- тема применяется в двух местах: head-скрипт (до первой отрисовки) и applyTheme() (клик). меняешь тему — правь оба места.
- localStorage у file:// и http://127.0.0.1:8792 — разный: тема и память последнего файла между ними не переносятся.
- файрфокс рисует светлый скроллбар поверх тёмной темы: каждой теме нужен свой scrollbar-color.
- пустой буфер затирает файл: без guard'а (trim + confirm) сохранение трёх пробелов обнуляло файл.
- переносы строк нельзя считать через getClientRects — врёт на фрагментах шрифта; мерить блочными div'ами по offsetHeight (текущая версия — зеркало #back + CSS-счётчики).
- хранить file handle в IndexedDB для автосохранений — не надо: запись тихо уходит в старый файл прошлой сессии. снесено.
- serve.py при запуске открывает браузер (webbrowser.open); в тестах и на headless запускать с BROWSER=true.
- одинаковые имена папки и файла легко перепутать — в путях указывать полный путь, а не «туда же».
- playwright тянет браузеры из ~/.cache/ms-playwright только по умолчанию; в этом проекте используем системный chrome (channel='chrome'), ничего не качаем.
- тема может «ломаться» из-за расширений браузера: dark-mode и тема-расширения в firefox/chrome перекрашивают страницу поверх CSS. если цвета поехали — сначала отключить расширения или проверить в чистом профиле, и только потом лезть в код. (у нас поэтому тесты и были зелёные — playwright всегда стартует в чистом профиле.)
- тема меняется через CSS-transition (.18s): тест, читающий computed background сразу после клика #theme, видит промежуточный цвет. после клика — wait_for_timeout(300).
- A+/A− меняют root font-size, а хром бара был в rem: кластер прыгал под курсором на ~50px, «17px» висел на 6.9px выше кнопок, ячейка размера раздувалась (6.2rem). бар/кнопки/стат/сегмент — в px, rem остаётся тексту, номерам строк и гуттеру.
- `.bar span{color:var(--dim)}` красит и подписи внутри кнопок: цвет текста вешать точечно (#fsval), общих span-селекторов в баре не заводить.
- файл могут править параллельно с агентом: перед правкой перечитывать содержимое и mtime, иначе правка идёт по устаревшему снимку (навигатор и палитра приехали, пока читались строки).
